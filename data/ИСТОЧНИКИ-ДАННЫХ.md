# Откуда данные базы продуктов

- `food-core.json`, продукты и блюда без бренда:
  - позиции с полем `s` = `usda:<номер>`: цифры из USDA FoodData Central, SR Legacy (2018-04), общественное достояние (CC0), русские названия наши
  - позиции с полем `s` = `off-median:<N>`: середина (медиана) КБЖУ по N товарам российской части Open Food Facts. Это производная база Open Food Facts, она распространяется по лицензии ODbL 1.0 вместе с этим файлом
- `food-off-ru.json`, товары из магазинов со штрих-кодом: выборка из Open Food Facts (https://world.openfoodfacts.org), товары с отметкой страны «Россия» или российским штрих-кодом 460-469, с заполненными калориями, белками, жирами и углеводами, прошедшие проверку по коэффициентам ТР ТС 022/2011 (приложение 4). Выгрузка от 22.10.2026. Содержит данные Open Food Facts, доступные по лицензии Open Database License (ODbL 1.0, https://opendatacommons.org/licenses/odbl/1-0/), отдельные записи по Database Contents License (DbCL 1.0). Способ выборки: скрипты в `_src/data-build/`
