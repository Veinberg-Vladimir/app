# Сборка базы продуктов (22.10.2026)

1. `sr_extract.py`: USDA FoodData Central SR Legacy (FoodData_Central_sr_legacy_food_csv_2018-04.zip) → калории, белки, жиры, углеводы по номеру продукта
2. `out_G1..G5.json`: какие номера USDA взяты и как названы по-русски (отбор и названия, цифры не трогались)
3. `off_extract.py` + `off_clean.py`: выгрузка Open Food Facts (en.openfoodfacts.org.products.csv.gz) → товары с отметкой «Россия» или штрих-кодом 46…, с полным КБЖУ, проверка по коэффициентам ТР ТС 022/2011 (белки и углеводы 4, жиры 9 ккал/г: расхождение больше 25 % и 30 ккал отсеивается) → `../../data/food-off-ru.json`
4. `ru_generics.py`: российские продукты, которых нет в USDA (творог, кефир, сметана, докторская и др.) = медиана по товарам Open Food Facts, подходящим под правило названия
5. `build_core.py`: российские продукты + отобранные USDA → `../../data/food-core.json`; при совпадении названия берётся российская строка

Обновление товаров: скачать свежую выгрузку Open Food Facts, прогнать шаги 3-5
